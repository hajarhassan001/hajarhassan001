## SinaCare Admin

**Production Flutter Desktop Business Management System**

SinaCare Admin is a real production desktop application developed with Flutter and currently deployed and actively used in daily business operations.

It is not a prototype, learning project, or demo application. The system was developed around actual operational requirements and continues to evolve based on real production usage.

The project involves interconnected business, financial, inventory, and administrative workflows where changes in one part of the system can directly affect other areas.

### Main Business Areas

The system includes functionality for:

- Product management
- Inventory management
- Customer management
- Orders
- Invoices
- Sales returns
- Customer accounts
- Accounts receivable
- Payment workflows
- Financial reporting
- Operational reporting
- Business document generation
- Local data management
- Data synchronization
- Administrative workflows

### Orders & Invoicing

The application manages real order and invoicing workflows rather than isolated records.

Order-related functionality is connected to:

- Customers
- Products
- Inventory
- Pricing
- Customer balances
- Financial records
- Reporting

This requires maintaining consistent behavior between multiple parts of the application when business operations change.

### Customer Accounts & Receivables

SinaCare Admin includes customer account and receivables workflows for tracking financial activity related to customers.

The application works with:

- Customer balances
- Receivables
- Payments
- Statements
- Financial records
- Related reporting workflows

These workflows require maintaining accurate relationships between transactions and customer financial data.

### Sales Returns

The system includes sales return workflows integrated with the rest of the application rather than implemented as an isolated feature.

Returns can affect operational and financial data, so their implementation must remain consistent with the application's broader business rules.

### Inventory

Inventory functionality is connected to products and business operations throughout the system.

The application manages product and stock-related information while maintaining consistency with other workflows such as orders and returns.

### Reporting

SinaCare Admin contains financial and operational reporting capabilities based on actual application data.

Reporting areas include business information related to:

- Sales
- Receivables
- Customer accounts
- Cash flow
- Operational records

The application also generates business documents used within actual workflows.

### Local & Remote Data

The system works with both local application data and remote services.

This requires handling:

- Local persistence
- Remote data access
- Synchronization
- Data consistency
- Failure scenarios
- Application state changes

### Architecture

SinaCare Admin is organized using a structured Flutter architecture with clear separation between application responsibilities.

The project uses concepts including:

- Feature-Based Architecture
- Clean Architecture
- Core Layer
- Data Layer
- Domain Layer
- Presentation Layer
- Repository Pattern
- Use Cases
- Cubit State Management
- Dependency Injection
- Shared services and utilities

The goal is to allow the codebase to continue growing without turning individual features into tightly coupled modules.

### Production Development

Development work includes:

- Fixing production defects

The application continues to be developed as real operational requirements evolve.
